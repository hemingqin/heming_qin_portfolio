# Resume PDF

Place your resume PDF here as:

    Heming-Qin-Resume.pdf

so that the final path is:

    /public/resume/Heming-Qin-Resume.pdf

The Resume page (`src/app/resume/page.tsx`) automatically detects whether this
file exists. If it's missing, the page renders a clear "resume not yet added"
placeholder instead of failing. Once you add the file, refresh the page — no
code changes needed.
