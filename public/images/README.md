# Screenshots & Media

Drop project/experience screenshots, diagrams, and product images here, e.g.:

    /public/images/obvs/dashboard.png
    /public/images/oppo/rtt-feature.png

Then reference the path (e.g. `/images/obvs/dashboard.png`) in the `src`
field of the relevant `MediaItem` inside `src/data/experiences.ts` or
`src/data/projects.ts`. Any gallery entry left without a `src` automatically
renders a clean placeholder instead of a broken image.
